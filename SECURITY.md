## Security Policy

If you believe you have found a security vulnerability in DTVM, please do **not**
open a public GitHub issue.

### Private reporting

Send the report to:

- `shaoding.zw@antgroup.com`

Please include as much of the following information as possible:

- affected version, commit, or branch
- impact assessment
- reproduction steps or proof of concept
- any logs, traces, or crash output that help validate the issue

We do not currently run a public bug bounty program.

For non-security bugs and feature requests, please use the normal GitHub issue
templates instead.
