## Support

This repository hosts the open-source DTVM runtime, compiler, tests, and public
SDK references.

### Before opening a question issue

Please check these resources first:

- `README.md`
- `docs/start.md`
- `docs/user-guide.md`

### SmartCogent

SmartCogent is referenced in the project overview, but it is **not open-sourced
in this repository at the moment**.

For product information, demos, and trial details, visit:

- https://smartcogent.zan.top/

### SDK repositories

Related SDK repositories:

- DTVM C++ SDK: https://github.com/DTVMStack/DTVM_CppSDK
- DTVM Solidity SDK: https://github.com/DTVMStack/DTVM_SolSDK

### Bugs and feature requests

- Use GitHub issues for reproducible bugs and product feature requests.
- For potential security vulnerabilities, follow `SECURITY.md` instead of
  opening a public issue.
